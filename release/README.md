# مستودع التحديثات الداخلية وحزم التطبيق (In-App Releases)

هذا المجلد يحتوي على حزم التطبيق (APKs) وملف التحقق من التحديثات التلقائية (`version.json`) لدعم التحديث الداخلي الذاتي داخل التطبيق مباشرة:

## هيكل التحديثات
1. **`v1.apk`**:
   - حزمة الإصدار الأساسي الحالي المثبتة على الهاتف.
2. **`v2.apk`**:
   - حزمة الإصدار الجديد عند صدور التحديث.
3. **`version.json`**:
   - ملف البيانات الوصفية (Metadata) الذي يفحصه التطبيق تلقائياً عند التشغيل أو عند الضغط على "فحص التحديثات".
   - يحتوي على:
     - `versionName`: اسم الإصدار الأحدث (مثل `v2`).
     - `versionCode`: رقم الإصدار التزايدي (مثل `2`).
     - `apkUrl`: رابط التنزيل المباشر لحزمة الـ APK.
     - `changelog`: تفاصيل ما تم تحديثه ليظهر للمستخدم في نافذة التحديث داخل التطبيق.

## آلية عمل التحديث الداخلي:
- عند فتح التطبيق، يقوم `AppUpdateManager` بالاتصال بـ GitHub أو ملف `version.json`.
- إذا وجد أن نسخة التطبيق الحالية `v1` والمنشور على GitHub هو `v2`:
  1. تظهر نافذة منبثقة تلقائية في التطبيق تشرح الميزات الجديدة في `v2`.
  2. يضغط المستخدم على **تنزيل وتثبيت التحديث**.
  3. يبدأ التنزيل الداخلي مع شريط تقدم مباشر.
  4. عند اكتمال التنزيل، يقوم التطبيق بفتح شاشة التثبيت التلقائي للنظام عبر `FileProvider`.

# حزمة تطبيق راوي AI (نسخة الاختبار والتجربة على الهاتف)

## ملف الحزمة
- **اسم الملف:** `123.apk`
- **المسار:** `123/123.apk`
- **الحجم:** ~28 ميجابايت
- **نوع الحزمة:** Android Debug APK كامل ومجمّع مع كافة الميزات والتحديثات

## الميزات المضمّنة في هذه النسخة:
1. **شاشة إنشاء القصة (StoryCreationScreen):**
   - حقل إدخال فكرة القصة وتحديد النمط ونسبة الأبعاد وعدد المشاهد.
   - زر **«إنشاء»** لتشغيل طلب Gemini API وإنتاج السيناريو والمشاهد.
2. **استوديو تحليل يوتيوب (YouTube Remaker):**
   - تحليل روابط يوتيوب عبر نموذج `gemini-3.1-pro-preview` وتوليد نسخة أصلية شبيهة.
3. **محرر المشاهد وتعديل النصوص والصور قبل التصدير:**
   - تعديل نصوص السرد ووصف الصور بحرية تامة.
   - توليد صور المشاهد بدقة عالية عبر `gemini-3.1-flash-image-preview`.
   - توليد التعليق الصوتي الدرامي (TTS) عبر `gemini-3.8-flash-tts` وتشغيله.
   - توليد الموسيقى التصويرية التصويرية عبر `lyria-3-clip-preview` مع مشغل صوت مدمج.
   - إمكانية إنتاج فيديو سينمائي عبر `veo-3.1-fast-generate-preview`.
4. **المصادقة والتخزين السحابي:**
   - تسجيل الدخول بحساب Google عبر `CredentialManager`.
   - حفظ القصص والمشاهد ومزامنتها في Cloud Firestore.
5. **مساعد راوي المباشر (Gemini Live Companion):**
   - عصف ذهني تفاعلي عبر `gemini-3.8-live`.

## طريقة التنزيل والتثبيت على الهاتف من GitHub:
1. افتح مستودع المشروع على GitHub من هاتفك أو حاسوبك.
2. توجّه إلى المجلد `123/` واضغط على الملف `123.apk`.
3. اضغط على زر **Download** (أو **View Raw**).
4. بعد تنزيل الملف على الهاتف، افتحه واضغط **تثبيت (Install)**.
   *(إذا ظهر تنبيه الأمان، فعّل خيار "السماح بتثبيت التطبيقات من هذا المصدر / Install Unknown Apps").*
5. استمتع بتجربة التطبيق مباشرة على هاتفك!

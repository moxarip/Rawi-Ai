# تطبيق راوي AI (Rawi AI Studio)

تطبيق متكامل لإنتاج الأفلام والقصص السينمائية بالذكاء الاصطناعي مع التعليق الصوتي الدرامي والموسيقى التصويرية وتصدير الفيديو للهاتف ونظام التحديثات الداخلية التلقائية.

---

## 📱 حزم التثبيت والتحديث المتاحة (Releases)

| الملف | الوصف | المسار |
| :--- | :--- | :--- |
| **`v1.apk`** | حزمة الإصدار الأساسي للتثبيت على الهاتف | `release/v1.apk` و `123/v1.apk` |
| **`v2.apk`** | حزمة التحديث الجديد المجمّعة والمحدثة | `release/v2.apk` و `123/v2.apk` |
| **`version.json`** | ملف التحقق من التحديثات الداخلية عبر التطبيق | `release/version.json` و `123/version.json` |

---

## 🚀 كيفية التثبيت والتحديث على الهاتف:

### 1. التثبيت لأول مرة:
1. حمّل ملف **`v1.apk`** (من المجلد `release/` أو `123/`).
2. ثبّت الحزمة على هاتفك (مع تفعيل خيار "تثبيت التطبيقات من مصادر غير معروفة" إذا طُلب منك).
3. افتح التطبيق وسجّل الدخول بحساب Google.

### 2. التحديث الداخلي التلقائي (In-App Update):
- التطبيق مبرمج بنظام فحص داخلي تلقائي عبر فئة `AppUpdateManager`.
- بمجرد فتح التطبيق، يكتشف فورياً توفر التحديث **`v2`** ويعرض نافذة منبثقة تفاعلية:
  - استعراض المميزات الجديدة في التحديث.
  - زر **«تنزيل وتثبيت التحديث»** مع شريط تقدم مباشر.
  - فتح معالج التثبيت تلقائياً وتحديث التطبيق من داخله دون الحاجة للمتصفح.
- يمكنك أيضاً في أي وقت التوجه إلى شاشة **«الحساب» (Profile)** والضغط على زر **«فحص التحديثات»** للتحقق اليدوي.

## 🌟 ما الجديد في إصدار v2:
1. **ضبط مدة جميع المشاهد:** كل مشهد مدته 10 ثوانٍ متزامنة بالكامل مع السرد الصوتي والمؤثرات.
2. **تجميع الفيلم الكامل:** تجميع المشاهد مع السرد الصوتي والموسيقى التصويرية في فيديو سينمائي متكامل.
3. **زر تصدير للهاتف:** زر مخصص ومباشر لحفظ وتنزيل فيديو MP4 إلى استوديو الهاتف ومجلد الوسائط بنقرة واحدة.
4. **التبديل الفوري لمواقع ومزودات الذكاء الاصطناعي:** تغيير مزود الصور أو محرك الفيديو مع تحديث مباشر لبطاقات المحرر وإمكانية إعادة التوليد الجماعي.
5. **مسح القصة القديمة تلقائياً:** بدء قصة جديدة يمسح القصة السابقة فورياً من الذاكرة والواجهة.
6. **حل مشكلة الخروج المفاجئ:** 
   - إضافة تأكيد مزدوج عند السحب أو الضغط على زر الرجوع لمنع الخروج العرضي.
   - رفع سقف الذاكرة (`largeHeap="true"`).
   - تثبيت درع الحماية البرمجي `CrashShield` لالتقاط أي استثناءات مفاجئة واستعادة استقرار التطبيق.

## ⚙️ كيفية إصدار تحديث مستقبلي (v3 وما بعدها):
عند رغبتك في إطلاق تحديث جديد مستقبلاً:
1. قم بتجميع الـ APK الجديد وسمّه `v3.apk` وضعه داخل مجلد `release/`.
2. عدّل ملف `release/version.json`:
   ```json
   {
     "versionCode": 3,
     "versionName": "v3",
     "apkUrl": "https://raw.githubusercontent.com/{username}/{repo}/main/release/v3.apk",
     "changelog": "اكتب هنا تفاصيل وميزات التحديث الجديد..."
   }
   ```
3. ارفع التغييرات إلى مستودع GitHub؛ سيكتشف التطبيق التحديث الجديد فوراً ويعرضه للمستخدمين لتنزيله وتثبيته تلقائياً!
